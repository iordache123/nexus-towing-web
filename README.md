# Nexus Towing

Website de prezentare generat pentru servicii de tractări auto și asistență rutieră non-stop în București și Ilfov.

## Rulare locală

```bash
npm install
npm run dev
```

Site-ul rulează implicit la [http://localhost:3000](http://localhost:3000).

## Verificări

```bash
npm run lint
npm run build
```

## Conținut

Textele, prețurile, datele de contact și imaginea hero sunt materiale demo generate pentru prezentare. Înainte de publicare live, înlocuiește-le cu informațiile comerciale reale.
